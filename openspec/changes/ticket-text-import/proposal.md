# Импорт обращения из текстового файла

## Проблема

Обращения можно создать только ручным вводом заголовка и описания в веб-форме. Пользователи часто получают описание уже готовым `.txt`-файлом и вынуждены переносить его вручную.

## Изменение

В существующую форму проекта добавляется выбор `.txt`-файла. Первая непустая строка заполняет заголовок, оставшийся текст — описание. Поля остаются редактируемыми, а создание выполняется существующим API после ручной отправки формы.

## Границы

Этот change не меняет API и модель хранения обращений. Прикрепление архивов логов, их ticket-scoped индексация, retrieval по user flow/Markdown и маршрутизация LangGraph описаны в `docs/superpowers/specs/2026-11-17-ticket-context-rag-design.md` и будут реализовываться отдельными совместимыми этапами.
