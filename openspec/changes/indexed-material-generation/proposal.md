# Генерация документации и User Flow по индексам

## Зачем

Генерация материалов сейчас представлена frontend-реестром без зарегистрированной реализации. Следующий генератор должен опираться на раздельные индексы проекта, а не пытаться передавать модели весь репозиторий или набор документов.

## Что меняется

Генератор документации использует актуальный индекс кода. Генератор User Flow использует актуальные индексы кода и документации одновременно, чтобы связывать действия пользователя с фактическими компонентами системы и подтверждённым поведением. Пользователь может выбрать любую чат-модель из рабочего пространства. Результаты сохраняются как локальные материалы проекта и доступны для проверки человеком.

## Границы

Confluence и другие удалённые хранилища не являются местом назначения генерации. User Flow остаётся черновиком до подтверждения человеком. Генератору передаются только выбранные поиском фрагменты из нужных индексов.
