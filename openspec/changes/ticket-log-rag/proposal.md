# Ticket-scoped RAG для архивов логов

## Проблема

Сейчас пользователь не может приложить архив логов к обращению, а ticket-agent ищет только в индексах проекта. Из-за этого расследование теряет фактические сигналы конкретного инцидента и может ошибочно приписать нехватку диска, памяти или OOM дефекту приложения.

## Изменение

Добавить привязанные к issue архивы `.zip` и `.tar.gz`, безопасное извлечение поддерживаемых текстовых файлов, отдельный ticket-scoped гибридный индекс и retrieval по запросам триажа. Вложения получают статус обработки; агент запускается только после завершения индексации всех вложений. Найденные фрагменты входят в общий evidence dossier с путём, строками и временными метками.

## Границы

Исходные архивы остаются артефактами issue в S3 и не отправляются целиком модели. Индекс логов одного issue недоступен другому issue и не включается в общий поиск проекта. MCP, автоматический сбор логов и LangGraph-маршрутизация узких специалистов остаются отдельными будущими этапами.
