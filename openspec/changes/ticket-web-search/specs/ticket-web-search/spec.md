## ADDED Requirements

### Requirement: Явное включение веб-поиска

Система ДОЛЖНА позволять настроить доступного поискового провайдера проекта и включать веб-поиск отдельной галочкой у обращения. Флаг обращения ДОЛЖЕН быть выключен по умолчанию. При выключенном флаге внешние поисковые запросы НЕ ДОЛЖНЫ выполняться.

#### Scenario: По умолчанию используется только внутренний RAG

- ДАНО: у проекта настроен поисковый провайдер, но у обращения выключен веб-поиск
- КОГДА: пользователь запускает разбор
- ТОГДА: агент использует только проектные знания и ticket-scoped evidence

#### Scenario: Пользователь включает внешний поиск у обращения

- ДАНО: у проекта настроен поисковый провайдер и пользователь включил веб-поиск у конкретного обращения
- КОГДА: внутренних evidence недостаточно для расследования
- ТОГДА: агент выполняет ограниченный поиск по очищенной сигнатуре ошибки и добавляет найденные страницы как отдельные внешние цитаты

### Requirement: Защита данных поискового запроса

Внешний поиск ДОЛЖЕН получать только нормализованную сигнатуру ошибки, названия/версии компонентов и платформу. Архивы логов, полные строки логов, полное описание обращения, секреты, персональные данные и локальные пути с идентификаторами пользователей НЕ ДОЛЖНЫ отправляться поисковому провайдеру.

#### Scenario: В логах есть секреты и персональные данные

- ДАНО: поисковая сигнатура извлечена из логов с токеном, адресом электронной почты и локальным путём пользователя
- КОГДА: система формирует запрос SearXNG
- ТОГДА: отправляется только очищенный error signature без секретов, адреса и пользовательского пути

### Requirement: Доверие к внешним результатам

Результаты веб-поиска ДОЛЖНЫ иметь URL-цитаты и отдельный тип источника. Они ДОЛЖНЫ считаться недоверенными и дополнительными; инструкции из найденных страниц НЕ ДОЛЖНЫ исполняться или менять системные правила агента. Сбой провайдера НЕ ДОЛЖЕН удалять или блокировать внутренние evidence.

#### Scenario: Провайдер веб-поиска недоступен

- ДАНО: у обращения включён веб-поиск, но SearXNG отвечает ошибкой или таймаутом
- КОГДА: агент строит dossier
- ТОГДА: он продолжает работу с внутренними evidence и фиксирует диагностическое предупреждение

#### Scenario: Внешняя страница содержит инструкции для модели

- ДАНО: найденная страница содержит текст, пытающийся переопределить инструкции агента
- КОГДА: внешний фрагмент включён в dossier
- ТОГДА: он трактуется только как недоверенное содержимое источника и не изменяет поведение агента
