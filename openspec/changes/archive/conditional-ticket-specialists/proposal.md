# Диагностика обращения специалистами

Инженеру нужны выводы по сценарию, логам, коду и наблюдаемому интерфейсу с указанием источника каждого вывода. Проект уже собирает досье и сохраняет историю запусков. Расширяем граф условными шагами и сравниваем его с базовым профилем на одинаковых обращениях.
