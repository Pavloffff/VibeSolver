## ADDED Requirements

### Requirement: Просмотр снимка исходного кода проекта

Система ДОЛЖНА предоставлять в рабочем пространстве проекта просмотр дерева импортированных исходников и предпросмотр файлов в режиме чтения. При открытии дерева система ДОЛЖНА выбирать снимок, связанный с последним успешным импортом исходников этого проекта, и сохранять идентификатор снимка при переходе между папками, ветками и файлами. Система ДОЛЖНА брать список веток из снимка и его файлов. Для импорта без веток система ДОЛЖНА открывать дерево без выбора ветки.

#### Scenario: Повторный импорт во время просмотра

- **ДАНО** пользователь открыл дерево проекта из успешного импорта
- **КОГДА** импорт завершается повторно и пользователь открывает файл из уже показанного дерева
- **ТО** система ДОЛЖНА открыть файл из того же снимка, а при обновлении дерева выбрать снимок нового успешного импорта

#### Scenario: Новый импорт завершился с ошибкой

- **ДАНО** у проекта есть снимок успешного импорта
- **КОГДА** более поздний импорт выполняется или завершился с ошибкой
- **ТО** система ДОЛЖНА продолжать показывать исходники из последнего успешного импорта

#### Scenario: Снимок исходников отсутствует

- **ДАНО** успешного импорта ещё не было или последний успешный импорт выполнен до появления снимков
- **КОГДА** пользователь открывает просмотр исходников
- **ТО** система ДОЛЖНА объяснить, что для просмотра нужен импорт или повторный импорт соответственно, и сохранить состояние импорта и хранилища при чтении

### Requirement: Загрузка дерева исходников по страницам

Система ДОЛЖНА выдавать непосредственных потомков запрошенной папки порциями ограниченного размера в стабильном порядке. Пагинация ДОЛЖНА быть привязана к проекту, снимку, ветке и папке. Для списка система ДОЛЖНА использовать метаданные снимка без загрузки содержимого файлов. Клиенту ДОЛЖНЫ передаваться только метаданные, необходимые для навигации и предпросмотра.

#### Scenario: Большая папка

- **ДАНО** в папке больше записей, чем помещается на одной странице
- **КОГДА** пользователь запрашивает следующие страницы той же папки
- **ТО** система ДОЛЖНА возвращать все её непосредственные записи без пропусков и повторов

### Requirement: Ограниченный предпросмотр файла

Система ДОЛЖНА проверять принадлежность снимка успешному импорту запрошенного проекта и искать файл по точной ветке и относительному пути в этом снимке. Ключ хранилища ДОЛЖЕН извлекаться сервером из записи файла. Система ДОЛЖНА проверять размер файла по метаданным до обращения к хранилищу и ограничивать фактический объём чтения настроенным на сервере пределом. Предпросмотр ДОЛЖЕН показывать UTF-8-текст без исполнения или интерпретации содержимого как разметки. Для бинарных файлов, неподдерживаемых кодировок и файлов сверх лимита система ДОЛЖНА сообщать причину недоступности предпросмотра.

#### Scenario: Файл с таким же путём в другой ветке

- **ДАНО** один и тот же путь присутствует в двух ветках снимка
- **КОГДА** пользователь открывает файл в выбранной ветке
- **ТО** система ДОЛЖНА показать содержимое файла именно из этой ветки

#### Scenario: Запрос за пределами проекта или снимка

- **ДАНО** в другом проекте или снимке существует файл с запрошенным путём
- **КОГДА** поступает запрос со снимком чужого проекта, отсутствующей в снимке веткой или путём, выходящим за пределы дерева
- **ТО** система ДОЛЖНА отклонить запрос без чтения объекта из хранилища

#### Scenario: Файл нельзя показать в предпросмотре

- **ДАНО** пользователь выбрал бинарный файл, файл в неподдерживаемой кодировке или файл сверх лимита
- **КОГДА** открывается предпросмотр
- **ТО** система ДОЛЖНА показать причину, сохранив выбранные ветку и путь
