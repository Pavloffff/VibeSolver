# Рабочее место инженера и профили графа

Сейчас страница обращений объединяет настройки моделей всего проекта, очередь, создание тикета и просмотр результата. Поля трассировки показываются как JSON. Чтобы проверить исходник, на который ссылается ответ, инженеру приходится искать файл за пределами проекта.

Инженер получает отдельную вкладку «Граф решения» (Solver graph), где видит путь обращения, задаёт модели и сохраняет именованные профили проекта. На странице обращений остаются выбор профиля для запуска, переход к графу, очередь и результат. В источниках знаний можно читать импортированный код по веткам. Изменения работают в общем интерфейсе браузера и настольного клиента.
