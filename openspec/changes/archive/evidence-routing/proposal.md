# Маршруты расследования по фактическим данным

Сегодня документация может оказаться единственным основанием ответа. Журналы читаются после первичного поиска, а веб-поиск может предшествовать проверке гипотезы. Новый маршрут начинает с доступных фактов обращения, сверяет описание продукта с реализацией и запрашивает недостающий локальный факт после доступных проверок.
