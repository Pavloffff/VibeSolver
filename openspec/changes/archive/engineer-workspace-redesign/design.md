# Макет рабочего пространства

Центральная область заполняет доступную ширину между боковой навигацией и правым краем окна. Проекты, модели, настройки и граф используют общие поля. На широком экране очередь занимает меньшую часть пространства, выбранное обращение получает основной столбец. На узком экране инженер читает карточку и может вернуться к очереди.

В обзоре проекта инженер открывает источники знаний. Полноэкранное окно занимает весь экран приложения. В нём инженер выбирает категорию и читает файл рядом с деревом. Документация и пользовательские сценарии поддерживают редактирование. При просмотре кода указываются ветка и снимок, известные языки подсвечиваются.

В шапке обращений постоянно видна кнопка создания. Она открывает просторную форму, на телефоне форма занимает весь экран. Выбор источника определяет способ заполнения заголовка и описания. ZIP содержит один текст обращения в UTF-8. Для журналов есть отдельный выбор архива. Карточка показывает предложение, источники, параметры повторного разбора и журнал. Уточнение относится к конкретному запуску. Экспериментальный сбор замера интерфейса находится в отдельном разделе проекта.

Проверка ширины использует сохранённое обращение lab5 «QA · Какой маршрут возвращает все доклады?». До изменений при окне 1440 CSS-пикселей текст ответа занимал 798 пикселей в области шириной 593 пикселя. При окне 360 пикселей содержимое растягивало документ до 906 пикселей. После изменения длинная ссылка должна переноситься внутри карточки без потери текста.
