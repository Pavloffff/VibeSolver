# Требования: статистика индексов проекта

## ADDED Requirements

### Requirement: Сводка ресурсов проекта

Система ДОЛЖНА показывать число файлов импортированного проекта, локальных файлов документации и файлов User Flow.

#### Scenario: Ресурсы загружены

- ДАНО проект с импортированными файлами, документацией и User Flow
- КОГДА пользователь открывает страницу проекта
- ТОГДА блок статистики показывает количества для всех трёх групп

### Requirement: Результаты индексации в статистике

Система ДОЛЖНА отдельно показывать для индексов кода, документации и User Flow количество файлов, переданных индексатору, и созданных поисковых фрагментов, используя последний результат соответствующего запуска.

#### Scenario: Индекс завершён

- ДАНО завершённый запуск индекса с числом файлов и фрагментов
- КОГДА отображается статистика проекта
- ТОГДА для этого типа индекса показываются сохранённые значения запуска

#### Scenario: Индекс ещё не запускался

- ДАНО для типа индекса нет запуска
- КОГДА отображается статистика проекта
- ТОГДА система показывает, что результат пока отсутствует, а не выдаёт нулевое число фрагментов

#### Scenario: Последний запуск завершился ошибкой или устарел

- ДАНО последний запуск индекса имеет состояние ошибки или требует переиндексации
- КОГДА отображается статистика проекта
- ТОГДА система сохраняет доступные количества этого запуска и не маркирует их как актуальный успешный результат
