# Статистика проекта на основе индексов

## Зачем

Сейчас блок «Статистика проекта» показывает только число файлов импорта. Пользователь не видит, что именно уже обработал каждый индексатор, сколько получено поисковых фрагментов и сколько локальных материалов документации и User Flow участвует в проекте.

## Что меняется

Блок статистики будет показывать число импортированных файлов, локальных файлов документации и User Flow, а также результаты каждого индекса: обработанные файлы и созданные фрагменты. Значения берутся из существующих состояний index run и дерева локальных ресурсов проекта; отдельная копия статистики в базе не нужна.

## Область изменения

В этой итерации меняется только отображение статистики. Отчёты по языкам, разделам документации и диагностике не включаются: текущий API не предоставляет эти агрегаты, и их добавление потребовало бы отдельного контракта и запросов к чанкам.
