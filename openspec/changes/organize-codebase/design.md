# Техническое решение

- Интерфейсы репозиториев разместить в `domain/repositories/`, реализацию SQL — в `adapter/repositories/`; package `__init__.py` сохраняет текущий путь импорта как фасад.
- UI-карточки проекта вынести в отдельные компоненты рядом со страницей, состояние и API-оркестрацию оставить в `ProjectPage`.
- Глобальные стили сгруппировать в `styles/` по базовой оболочке, настройкам, проекту, режиму и адаптивным правилам; `styles.css` оставить точкой подключения.
- Не дробить небольшие модули с одной цельной ответственностью.
