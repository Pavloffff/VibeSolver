# Предложение: разложить крупные модули по ответственности

## Проблема

В нескольких местах backend и frontend связанные, но самостоятельные части собраны в одном файле. Это затрудняет поиск нужной реализации и развитие новых возможностей.

## Решение

Сгруппировать интерфейсы и реализации репозиториев backend по предметной ответственности, разделить крупную страницу проекта и разнести глобальные стили по областям интерфейса. Сохранить публичные импорты и поведение приложения.
