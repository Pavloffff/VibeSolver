# Предложение: экспериментальная заготовка песочницы

## Проблема

Целевой workflow должен уметь проверять будущие патчи изолированно. В текущем репозитории нет Docker runner boundary, policy для ресурсов или безопасного состояния по умолчанию.

## Изменение

Добавить backend-контракт выполнения, типизированную политику ресурсов и Docker command plan builder для одноразового контейнера. Функция помечается экспериментальной и выключена по умолчанию через переменные окружения. В этой фазе команды не исполняются: компонент готовит план для будущего runner и проверяет safety options.

## Границы

- LangGraph не вызывает executor; пользовательские обращения не запускают код или тесты.
- Docker socket, API endpoint для запуска, UI управления и копирование проекта не добавляются.
- План принимает только подготовленный snapshot без `.env`, `.git` и локальных credentials и требует `--network none`, read-only mount snapshot, отдельный временный workspace, лимиты CPU/RAM/PID/времени, удаление контейнера и ограничение прав.
- Настройки исполнения и образ контейнера задаются переменными окружения; образ должен быть закреплён digest-ом при включении.
