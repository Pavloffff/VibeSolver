# Предложение: управление материалами проекта

## Проблема

Сейчас к проекту можно прикрепить архивы документации и User Flow, но нельзя просматривать и изменять Markdown-материалы, обновлять существующие вложения или объединять несколько текстовых материалов.

## Решение

Разрешить добавлять архивы и Markdown-файлы для документации и User Flow. Markdown-материалы можно будет открыть внутри приложения, редактировать, сохранить поверх текущего материала или объединить с другим Markdown-файлом. Существующие архивы можно заменить новой версией. Действия генерации из кода и документации останутся в интерфейсе, но до появления LLM-провайдера сообщат, что генератор ещё не подключён; архитектура UI предусматривает регистрацию генератора.

## Границы

- Файлы хранятся в S3-совместимом хранилище, а проект хранит ссылки и метаданные ресурсов.
- Редактирование выполняется внутри приложения; открытие файловой системы пользователя не требуется.
- Подключение Confluence и реальная LLM-генерация не входят в эту реализацию.
