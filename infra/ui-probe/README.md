# Необязательная проверка интерфейса тестового стенда

Сервис считывает состояние одного заранее настроенного элемента уже работающего тестового стенда. Он не собирает и не запускает проверяемый проект и не управляет интерфейсом. Подключать сервис нужно только к доверенному тестовому стенду без производственных учётных данных и с изолированной сетью: JavaScript страницы выполняется, а сервер стенда сам отвечает за отсутствие побочных эффектов у запросов GET и HEAD.

## Настройка и запуск

Нужны Node.js и установленный локально Chrome или Edge. Пакет `playwright-core` версии 1.65.1 распространяется по лицензии Apache-2.0; браузер устанавливается отдельно. В каталоге `infra/ui-probe`:

```powershell
npm ci --ignore-scripts
$env:VIBESOLVER_UI_PROBE_BIND = '127.0.0.1'
$env:VIBESOLVER_UI_PROBE_PORT = '8794'
$env:VIBESOLVER_UI_PROBE_BROWSER = 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
$env:VIBESOLVER_UI_PROBE_DEFINITIONS = '{"projects":{"url":"http://127.0.0.1:8081/","role":"button","name":"Projects"}}'
$env:VIBESOLVER_UI_PROBE_TIMEOUT_MS = '10000'
$env:VIBESOLVER_UI_PROBE_CONCURRENCY = '1'
npm start
```

Адрес, порт, путь браузера, алиас и элемент в примере замените на параметры своего стенда. Сервис не содержит заранее заданных целей и не запускается без явно заданных адреса прослушивания, порта, пути браузера и JSON-объекта определений. Каждый ключ объекта — алиас из латинских букв, цифр, `_` или `-`; значение содержит только используемые поля `url`, `role`, `name`. URL должен быть HTTP(S), без встроенных учётных данных. Имена и роли выбирает администратор конфигурации, а не вызывающая сторона. Параметры времени ожидания и параллелизма необязательны: по умолчанию 10000 мс и 1 запуск; допустимы 1–60000 мс и 1–4 запуска.

API приложения обращается к сервису по внутреннему адресу и передаёт только алиас, например `GET /observe?probe=projects`. Ответ содержит роль, имя, размеры, видимость, доступность, состояние отметки и время наблюдения. Если элемент отсутствует или совпадений несколько, ответ — 502 без содержимого страницы. При превышении лимита параллелизма возвращается 429; неизвестный алиас и дополнительные параметры отклоняются. Сервис не имеет собственной аутентификации: ограничьте доступ к его порту доверенной внутренней сетью или локальным интерфейсом.

Для каждого запроса создаётся новый изолированный контекст без пользовательского профиля и сохранённых сессий. Разрешены только GET и HEAD основного фрейма на исходном origin, включая перенаправления внутри него. Подфреймы, переходы на другой origin, WebSocket, загрузки и service workers блокируются. При превышении времени браузер закрывается. Сервис не возвращает текст страницы, скриншоты, cookie или содержимое хранилищ.

## Проверка

```powershell
npm test
$env:VIBESOLVER_UI_PROBE_TEST_BROWSER = 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
npm test
npm audit --omit=dev
```

Без `VIBESOLVER_UI_PROBE_TEST_BROWSER` тест с реальным браузером пропускается. С указанным браузером он запускает временный локальный стенд, проверяет измерение кнопки и блокировку POST и подфрейма. Он не обращается к пользовательскому проекту.
