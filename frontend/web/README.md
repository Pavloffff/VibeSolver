# frontend/web

Веб-интерфейс VibeSolver: Vite + React + TypeScript (strict mode).

Здесь находятся: типизированный API-клиент, список источников и форма их регистрации (генерируется из `GET /api/v1/connectors`, без хардкода типов), статус импорта с опросом, экран выбора режима работы (local/remote), страница настроек и i18n-словари (`frontend/web/src/i18n/`: `en`/`ru`/`zh`).
